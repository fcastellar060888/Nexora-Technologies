# Cannapa ERP Enterprise v6.1

Actualización completa basada en la v6.0 verificada.

## Cambios principales
- Nuevo motor configurable de áreas operativas por sede.
- Jerarquía flexible para banco, bandeja, nave, cama, fila, posición, mesa, módulo, rack y cuarto.
- Estados operativos de infraestructura: activo, vegetativo, floración, limpieza, vacío, cuarentena y mantenimiento.
- Nuevo mapa de áreas por sede.
- Compatibilidad automática con los datos locales y respaldos de v6.0.
- React Router fijado en la rama 6.30.4 para evitar la alerta de seguridad de la rama 7 afectada.
- Corrección verificada de sintaxis de SiteMapPage.

La infraestructura describe lo físico. La ubicación y el historial del material vegetal deben registrarse mediante movimientos.
