# Actualizar a V6

1. Conserva una copia del proyecto actual o crea un commit antes de reemplazar archivos.
2. Reemplaza el contenido por esta versión.
3. Ejecuta por separado:

```bash
npm install
npm run audit:static
npm run build
```

4. Prueba abuelas, madres, creación de esquejes, cambio de fase, mapa, producto terminado, monedas y ventas.
5. Publica solo después de obtener `✓ built`.
