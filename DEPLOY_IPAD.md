1. Crea un Codespace nuevo.
2. Descomprime el ZIP.
3. Arrastra src, supabase, index.html, package.json, vite.config.js, netlify.toml y README.md.
4. Terminal: npm install
5. Terminal: npm run build
6. git add .
7. git commit -m "Cannapa ERP v1.0 Foundation"
8. git push
9. Conecta Netlify: build npm run build, publish dist.
