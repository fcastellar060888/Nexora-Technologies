# Cannapa ERP Enterprise V5.1

## Enfoque de esta entrega
- Corrección definitiva de alineación del menú lateral, incluida la sección Producción y poscosecha.
- Mapa único del cultivo con capas por lote, fase, genética y MIPE.
- Movimiento libre de naves, bancos y camas.
- Ajuste numérico de posición, ancho, alto y rotación.
- Asignación de lote a camas y bancos de propagación.
- Visualización de semana y fase directamente en el mapa.
- Plantas completas respetando filas y posiciones configuradas.
- Validación del lote biológico al momento del corte.

## Validación
```bash
npm run audit:static
npm run build
```
