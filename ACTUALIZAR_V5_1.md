# Actualizar a V5.1

1. Descarga un respaldo JSON desde Configuración.
2. Reemplaza el proyecto por esta entrega.
3. Ejecuta por separado:

```bash
npm install
```

```bash
npm run audit:static
```

```bash
npm run build
```

4. Publica con:

```bash
git add .
```

```bash
git commit -m "Cannapa ERP Enterprise V5.1 mapa y UX"
```

```bash
git push
```
