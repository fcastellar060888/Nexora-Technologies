# Cannapa ERP Enterprise V5.0 — Núcleo biológico y operativo

## Incluye
- Plantas abuela y alertas de renovación.
- Madres vinculadas a abuelas, lote de madres y duración objetivo.
- Lote biológico único desde el corte hasta el empaque.
- Supervivencia, mortalidad, descarte y enraizamiento.
- Objetivos de duración por fase y genética.
- Semana, día, fecha prevista y días restantes automáticos.
- Cambio de fase por lote con línea de tiempo.
- Centro de Operaciones con alertas de renovación y fase.
- Mapa único editable con naves, bancos de propagación y camas movibles.
- Camas dibujadas con filas y plantas por fila exactas.
- Redirección de croquis anteriores al mapa único.

## Validación ejecutada
- `npm run audit:static`: OK.
- `npm run build`: OK, 1663 módulos transformados.

## Instalación
1. Respaldar los datos actuales desde Configuración.
2. Reemplazar los archivos del proyecto.
3. Ejecutar `npm install`.
4. Ejecutar `npm run audit:static`.
5. Ejecutar `npm run build`.
